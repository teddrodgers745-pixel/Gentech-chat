# fix_notes — F3-cost-toggle

## Что было не так (как стоял гейт)
`MessageView._costWidgets` (lib/widgets/message_view.dart) второй строкой метода:
`if (!settings.showCost) return const <Widget>[];`
Ранний return полностью отключал весь блок — и сумму («≈ X ₽»), и счётчики
токенов («N ток.») — когда тумблер showCost выключен. Тест
F3-T-COST-LINE-SETTING-OFF (test/f3_cost_line_widget_test.dart) закреплял
этот дефект как эталон. Живой тест: «при выключении стоимости токены тоже
уходят» — строка исчезала целиком.

## Что поправил
1. **lib/widgets/message_view.dart, `_costWidgets`** — ранний return удалён.
   Гейт настройки showCost теперь применяется ТОЛЬКО к денежной сумме:
   `final hasAmount = settings.showCost && c.cost != null && currency.isNotEmpty;`
   При выключенном тумблере hasAmount == false, и код идёт в ветку
   `else if (tokens > 0) { text = '$tokens ток.'; }` — рубли скрыты, токены
   остаются (контракт R4/F3: токены — когда известны; стоимость — когда
   известна И включена). Обновлены док-комментарии метода.
2. **test/f3_cost_line_widget_test.dart** — ЯВНОЕ обновление теста
   (прецедент: тест парсера reasoning в R4). Старый F3-T-COST-LINE-SETTING-OFF
   («выключенный показ — строки нет») заменён на тесты НОВОГО поведения,
   все 4 комбинации покрыты:
   - F3-T-COST-LINE-BOTH: вкл × токены известны → «≈ 1,875 ₽ · 30 ток.»;
   - F3-T-COST-LINE-AMOUNT-ONLY: вкл × токенов нет → «≈ 1,875 ₽»;
   - F3-T-COST-TOGGLE-OFF-TOKENS-STAY: выкл × токены известны → «30 ток.»,
     без «≈»; строка не исчезает целиком (главная проверка живого дефекта);
   - F3-T-COST-TOGGLE-OFF-NO-TOKENS: выкл × токенов нет → строки нет
     (приёмка F3-LIVE-COST-TOGGLE, п.3);
   - плюс F3-T-COST-TOGGLE-OFF-EMPTY-COST: пустой MessageCost → строки нет.
   Переключение showCost вынесено в хелпер `setShowCost` с восстановлением
   прежнего значения в tearDown — тесты не зависят от порядка в файле.
3. **lib/screens/settings_screen.dart** — подпись тумблера «Показывать
   стоимость ответов» уточнена: «Суммы „≈ X ₽" под ответами и итоги в
   списке чатов. Счётчики токенов („N ток.") видны всегда» — текст теперь
   совпадает с поведением: скрывается только стоимость, не токены.
4. TEMP-DIAG, R1–R6, F1–F5, F2-settings-probe не затронуты; пути
   chat_screen._sumRoundCosts / TextPart / MessageCost не менялись — там
   контракт уже корректен (суммирование токенов не гейтится тумблером),
   дефект был только в точке отображения `_costWidgets`.

## Что стоит улучшить рядом (не чиня сейчас)
- Итоги стоимости в списке чатов (HistoryDrawer/заголовки) тоже рендерятся
  из MessageCost — стоит один раз прогнать живым тестом, что выключенный
  тумблер скрывает там только суммы (код прислан не был — файл
  lib/screens/history_drawer.dart в задаче не прикладывался, проверка не
  выполнялась).
- Если сумма неизвестна у провайдера (usage без cost_rub), пользователь при
  выключенном тумблере и включённом не увидит разницы — можно добавить в
  настройки пояснение, что «N ток.» при пустой сумме означает, что
  провайдер не прислал поле стоимости (диагностика по_Argону в п. «Как
  проверить»).

## Как проверить живым тестом (F3-LIVE-COST-TOGGLE)
1. Стоимость ВКЛЮЧЕНА (Настройки → Экономика): ответ модели → полная
   строка «≈ X ₽ · N ток.».
2. Стоимость ВЫКЛЮЧЕНА, токены известны: под ответом «N ток.», без «≈ X ₽».
3. Стоимость ВЫКЛЮЧЕНА, токенов нет: строки под ответом нет вовсе.
4. Диагностика (без лога с телефона):
   - при ВЫКЛЮЧЕННОМ тумблере видно «N ток.», а при ВКЛЮЧЁННОМ — всё равно
     только «N ток.» без «≈ X ₽» → usage приходит, но без cost_rub/cost;
   - «N ток.» нет ни при каком тумблере → провайдер не прислал блок usage
     вообще (проверить stream_options.include_usage для стрима).
