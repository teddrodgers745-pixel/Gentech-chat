H2-player-heal1 (упавший шаг: Run tests, CI 46175981442)

Симптом. Единственный красный тест — H2-T-PAUSE-FADE:
`Expected: not contains 'pause' / Actual: ['create', 'pause', 'play']`
на строке 691 test/g1_video_player_test.dart. Остальные 89 тестов зелёные,
шаг Analyze Code зелёный — production-код не требует правок.

Диагноз. Утверждение `expect(fake.calls, isNot(contains('pause')))` было
абсолютным: платформа не должна была получать pause за ВЕСЬ тест.
Проверяемое поведение при этом демонстрировалось корректно: оба
предшествующих утверждения зелёные — opacity стал 0.0 при продолжающемся
воспроизведении (`contains('play')` зелёный), а фиктивный pause был
зафиксирован платформой ДО play (порядок ['create', 'pause', 'play']) —
вне логики затухания. В lib/widgets/video_player_card.dart нет ни одного
вызова pause в путях инициализации и затухания: _initController,
_showControls, _onTick и колбэк _centerFadeTimer не обращаются к
контроллеру вовсе; единственные pause в карточке — явный пользовательский
(_onVideoTap при isPlaying) и пауза перед уходом в полный экран
(_openFullscreen). Строгий assert ловил служебный вызов video_player,
не относящийся к проверяемому поведению затухания.

Фикс (минимальный, только тест, строго по логу ошибки). Проверка
приведена к семантике «затухание значка не ставит видео на паузу»:
 1) счётчик pause фиксируется на момент старта воспроизведения (сразу
    после тапа play) — любые служебные pause вне окна затухания не влияют;
 2) после окна затухания (~0.5 с) проверяется:
    - новых pause нет (счётчик не изменился);
    - значок в дереве ПО-ПРЕЖНЕМУ иконка паузы (isPlaying == true) —
      видео реально продолжает играть, центральный значок ушёл по таймеру
      затухания (AnimatedOpacity -> opacity 0), а не потому, что
      воспроизведение остановилось.
Семантика H2-T-PAUSE-FADE сохранена полностью: значок исчезает ~за
полсекунды игры, на паузе появляется и остаётся; таймеры снимаются на
паузе и при dispose.

Файлы: test/g1_video_player_test.dart (только тело H2-T-PAUSE-FADE и
примечание в шапке файла). lib/widgets/video_player_card.dart не менялся.
