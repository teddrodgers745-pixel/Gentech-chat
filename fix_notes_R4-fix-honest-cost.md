# R4-fix-honest-cost-heal2

## Статус

**Исправление не завершено.** Доступа к Flutter, репозиторию для запуска тестов и устройству в этой среде нет. Ни исходный `flutter test`, ни новый именованный тест здесь не запускались. Сборку зелёной считать нельзя.

## Что изменено

В тесте повреждённой записи каталога строка заменена числом: в универсальной ветке `ProviderCatalogService.parseCatalogResponse` непустая строка намеренно поддерживается как идентификатор модели. Поэтому прежний фикстур `"not-a-map"` не был повреждённой записью для этого подключения.

Добавлен `T-R4-HEAL2-LIVE-CATALOG-STRING`: локальный HTTP-сервер отдаёт каталог со строковым идентификатором и повреждёнными элементами; тест проверяет путь `/v1/models` и результат `sync`. Тест подготовлен, но не исполнен. Это не проверка полного пути UI → API → UI.

## Оставшиеся причины падения

- `ProviderCatalogService._parseReasoning` нормализует и сортирует уровни, поэтому теряются исходные порядок и `none` из каталога. Нужно согласовать хранение сырых значений с отображением и отправкой; не заменять проверку теста каноническим списком только ради зелёного CI.
- `MessageCost.fromUsage` превращает отсутствие суммы в `0`, присваивает неуточнённому `cost` валюту USD, а `formatted` округляет сумму до двух знаков. Нужны неизвестная сумма и валюта без выдуманных значений, точное форматирование и совместимое чтение истории.
- В непотоковом `ChatService.sendMessage` usage промежуточного раунда с вызовом инструмента не выдаётся клиенту. После передачи каждого раунда необходимо обновить потребителей, включая `ChatScreen._runCompletion` и `ChatCompletionsExecutor`, не дублируя суммы и не смешивая валюты.
- `ChatService._describeError` любую 402 заменяет сообщением о балансе. Причину лимита ключа нужно сохранить из ответа; при неизвестной причине нельзя утверждать, что недостаточен баланс. Также требуется проверить отображение через `GenErrorMapper` и `ErrorBubble`, которые сейчас относят 402 к недостатку средств.

## Что проверить рядом

- `ChatScreen._generateImage` подставляет 1,5 ₽ при неизвестной оценке, оценивает токены по длине и применяет фиксированный курс. `_costWidgets` считает каждую сумму рублёвой. Это не соответствует фактическому usage.
- `ChatScreen._estimateWithCatalog` передаёт `hasVideo: isVideo`: тип выходной генерации не доказывает наличие видео на входе.
- `GenerationRequest.estimatedUsd` и `Artifact.cost` подписаны как USD, хотя оценщик может вернуть RUB; просмотрщик артефакта отображает доллар. Нельзя передавать туда сумму другой валюты без её сохранения.
- Участок `TEMP-DIAG-UNMODIFIABLE` не менялся. Отдельно стоит проверить передачу диагностических полей прогресса до `PendingPart`.

Для завершения нужны именованные исполняемые проверки полного пути: каталог и выбранные параметры → запрос → ответ каждого раунда → сохранение → UI, отдельно для потокового и непотокового режима, неизвестной суммы и валюты, точности, 402 с лимитом ключа и 402 без уточнения причины. Затем нужны успешные `flutter test` и сборка CI.

В присланном коде отсутствуют, в частности, `lib/core/catalog/parsing/reasoning_levels.dart`, специализированные парсеры каталога и `lib/core/utils/reasoning_mapper.dart`. Их версии на проверяемом коммите и остальные потребители необходимо получить перед согласованной правкой reasoning.
