# R4-fix-honest-cost-heal1

## Причина и исправление

В упавшем запуске использовался коммит `28fd7b5`. Файл `test/widget_test.dart` в нём отсутствует. Шаг CI `flutter create` генерирует недостающий шаблонный тест с `MyApp`, тогда как корневой виджет приложения называется `GenTechChatApp`. Поэтому анализатор останавливается до запуска тестов.

Добавлен собственный `test/widget_test.dart`: Flutter не должен заменять существующий файл при генерации платформы без `--overwrite`. Именованный виджет-тест проверяет реальный корневой виджет и начальную заставку, а не шаблонный счётчик. Логику генерации и защищённый диагностический участок изменение не затрагивает.

## Проверка и ограничения

Тест и сборка здесь не запускались; исправление **не подтверждено живым тестом**. Файл `lib/main.dart` не был прислан: имя виджета проверено по публичной ветке `main`, его нужно сверить с исправляемым коммитом.

В чистом checkout выполнить команду `flutter create` из workflow, убедиться, что `test/widget_test.dart` не перезаписан, затем запустить `flutter analyze`, `flutter test` и `flutter build apk --release`. Отдельно проверить результат `T-R4-HEAL1-APP-START`.

## Что проверить рядом

Если присланные реализации соответствуют исправляемому коммиту, тесты R4 могут обнаружить последующие проблемы: `MessageCost.fromUsage` подставляет ноль и USD при отсутствии данных, а `ChatService` не передаёт usage каждого непотокового раунда и заменяет причину HTTP 402 сообщением о балансе. Тесты до этих проверок в упавшем запуске не дошли.
