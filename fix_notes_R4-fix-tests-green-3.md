# R4-fix-tests-green-3-heal2

## Статус: исправление не завершено

Предложенный `message_part.dart` исправляет причины двух упавших проверок:
отсутствующая сумма больше не превращается в ноль, а валюта общего поля
`cost` без указания провайдера не считается USD. `cost_rub` по-прежнему
обозначает рубли и имеет приоритет.

**Не применять этот файл отдельно:** изменение `MessageCost.cost` на
`double?` требует обновить потребителей; иначе `flutter analyze` не
пройдёт. Полного исправления и зелёной сборки этим ответом не обеспечено.

## Что необходимо закончить

- В `ChatScreen._generateImage` и `_runCompletion` обработать nullable
  сумму перед сложением с `chat.totalCost`; не прибавлять неизвестные суммы
  или суммы неизвестной валюты. Для создаваемой стоимости изображения
  явно указать RUB.
- В `MessageView._costWidgets` показывать токены без выдуманной суммы;
  известную сумму показывать с её фактической валютой, не считая любое
  значение рублями и не округляя его до копеек.
- Проверить остальных потребителей `MessageCost.cost` во всём репозитории.
  `history_drawer.dart` в присланном коде отсутствует; его отображение
  `totalCost` тоже нужно учитывать при изменении логики суммирования.
- `ChatScreen._runCompletion` сейчас сохраняет только последний `usage`:
  при нескольких раундах инструментов суммарная стоимость ответа может
  быть неполной. Суммировать раунды нужно только при известной валюте и
  понятной семантике событий, не складывая разные валюты.
- Отдельно проверить существующую оценку изображения: сейчас при неизвестной
  цене подставляется 1,5 ₽, а USD переводится фиксированным курсом.
  Это не доказывает фактическое списание.

## Проверка после завершения

CI должен выполнить `flutter analyze`, `flutter test` и сборку APK. На
телефоне нужен именованный живой тест **T-R4-HEAL2-LIVE-USAGE**: отправить
запросы с ответами, содержащими только токены, `cost` без валюты и
`cost_rub`; проверить ответ в чате, подпись стоимости и её сохранение
после перезапуска. Этот тест здесь не выполнен.
