# R4-fix-tests-green-3-heal1

Исправление **частичное**; сборку нельзя считать зелёной или задачу готовой.

## Исправлено в ChatService

- Непотоковый раунд с вызовом инструмента раньше не отдавал `usage` клиенту. Теперь промежуточный раунд передаёт `usage` и источники отдельным чанком, не добавляя его текст к итоговому ответу.
- HTTP 402 больше не подменяется утверждением о недостатке баланса: сообщение сохраняет причину из ответа провайдера и использует нейтральную формулировку.

Для проверки этих изменений предназначены существующие HTTP-тесты `T2-UNIT-COST-NONSTREAM-ROUNDS` и `T2-UNIT-COST-402`. Их результат после правки ещё не получен.

## Осталось исправить до зелёной сборки

`MessageCost.fromUsage` в `lib/core/models/message_part.dart` по-прежнему превращает отсутствующую сумму в `0.0` и считает неопределённую валюту `USD`. Поэтому тесты `T2-UNIT-COST-TOKENS-ONLY` и `T2-UNIT-COST-UNSCOPED-ALIAS` всё ещё должны падать.

Корректное исправление требует сделать сумму допускающей `null` и согласованно обновить её потребителей, включая сохранение истории, `ChatScreen._runCompletion` и `MessageView._costWidgets`. Нельзя просто изменить тип без обновления потребителей: это сломает анализ или обработку отсутствующей суммы.

## Что проверить рядом

- `ChatScreen._runCompletion` сохраняет только последний `usage`, поэтому стоимость предыдущих раундов инструментов пока не отображается.
- `ChatCompletionsExecutor` не передаёт `usage` дальше в событиях генерации.
- Нужен именованный сквозной живой тест от интерфейса через запрос к API до отображения ответа и стоимости; отдельно проверить 402 с лимитом ключа и пустым телом. После зелёного CI пользователь должен выполнить проверку на телефоне.
