# R4-fix-tests-green-heal1: замечания

## Статус

Исправление **не завершено**. Выполнена только изолированная правка
`MessageCost.formatted`: она не округляет 1,875 до 1,88. Именованный тест
`T2-UNIT-COST-PRECISION` существует, но запустить его и остальные тесты
здесь не удалось. Живого доказательства поведения нет; зелёную сборку
заявлять нельзя.

## Причины остальных падений

- `ChatService.sendMessage`: в непотоковом режиме usage раунда с вызовом
  инструмента не выдаётся; выдаётся только usage финального раунда.
  При этом `ChatScreen._runCompletion` сохраняет лишь `lastUsage`, поэтому
  одной передачи всех раундов из сервиса недостаточно для честного итога UI.
- `ChatService._describeError`: для любого HTTP 402 подставляется утверждение
  о балансе вместо причины из ответа. Нужно сохранять безопасно извлечённую
  причину и использовать нейтральный текст при её отсутствии.
- `MessageCost.fromUsage`: отсутствие суммы превращается в `0`, а валюта
  неоднозначного `cost` без указания провайдера — в USD. Для исправления
  нужен nullable-контракт суммы и обновление сериализации и всех потребителей,
  включая отображение и подсчёт итогов.
- `ProviderCatalogService._parseReasoning` нормализует и сортирует уровни;
  тест `Polza chat: reasoning в top_provider, цена за 1M` ожидает исходные
  значения и порядок. Нужно согласовать контракт сырых каталожных значений
  с нормализацией для UI, не подставляя отсутствующие в каталоге уровни.

## Что проверить рядом

`ChatScreen._generateImage` подставляет стоимость 1,5 и курс 95 при
отсутствии надёжной суммы; это не фактический usage. Исполнитель
`ChatCompletionsExecutor` также не передаёт usage в события генерации.
Нужны именованные живые тесты полного пути API → сервис → исполнитель → UI:
несколько раундов, токены без суммы, неизвестная валюта и HTTP 402 с
причиной лимита; затем `flutter test` и release-сборка.

Для безопасного завершения нужны файлы ревизии упавшего запуска `b06587c`,
в частности `lib/widgets/message_view.dart`, модели и хранилище чата,
`generation_event.dart`, форматирование валюты и остальные потребители
`MessageCost` и `GenerationEvent`. Версия файлов из публичного `main`
относится к `f4db9ed` и не доказывает состояние упавшей ревизии.
Участок `TEMP-DIAG-UNMODIFIABLE` не изменялся.
