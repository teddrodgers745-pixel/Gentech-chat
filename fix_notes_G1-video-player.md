# fix_notes_G1-video-player

## Что было не так (разбор, пункт 0)

- **Чат** (`lib/widgets/message_view.dart`, класс `_PartVideo`, метод `_build`/`_init`): голый `VideoPlayer(c)` с одной кнопкой Play/Pause в футере. Никакой полосы перемотки, времени, звука, полного экрана, скачивания или шеринга. При падении `c.initialize()` — молчаливый `_staticCard()` без кнопки повтора и без возможности скачать. Тап по видео включал/останавливал воспроизведение без обратной связи (контролы не появлялись и не угасали).
- **Галерея** (`lib/features/gallery/artifacts_gallery_screen.dart`, класс `_GalleryTile`, ветка `item.isVideo`): жёстко захардкоженная статичная заглушка (Container + Icons.movie_outlined), БЕЗ GestureDetector и без onTap — видео из галереи невозможно было даже открыть.
- Дубликаты: аналогичные (устаревшие) реализации `_PartVideo`/`PartVideo`/`MessagePartVideo` в `lib/widgets/message_parts.dart` и `lib/widgets/message_view_parts.dart`.
- `lib/features/gallery/artifact_viewer.dart` (`_videoCard`): статичная карточка «Видео» с иконкой — просмотр недоступен.

## Что поправил

- **Новый единый виджет** `lib/widgets/video_player_card.dart` — `VideoPlayerCard`: тап = play/pause, VideoProgressIndicator (scrubbing) + время, звук/без звука, кнопка «На весь экран», повтор после конца (isCompleted → seekTo(0) + play), автоплей в фулскрине, угасание контролов через 4 с (на паузе остаются), постер «Загрузка видео…», карточка ошибки с «Повторить» (повторная загрузка того же URL, без новой генерации) + «Скачать»/«Поделиться».
- **Скачивание** `saveVideoToDevice`: Downloads (Android) → FilePicker → Downloads/Documents, состояние «Сохранение…»/«Видео сохранено: файл»/ошибка. **Шаринг** `shareVideo`: локальный файл — как есть, сетевой — временная копия + `Share.shareXFiles` (share_plus, уже в pubspec).
- **Полный экран** `openFullscreenVideo`: чёрный Scaffold с тем же плеером (автоплей), скачивание/шеринг в AppBar. Встроенный плеер ставится на паузу перед открытием, чтобы звук не шёл дважды.
- **Чат**: `_PartVideo` теперь тонкая обёртка над `VideoPlayerCard` — один и тот же плеер в чате и в галерее. Ошибка инициализации больше не «молчит»: карточка с повтором и действиями.
- **Галерея**: `_GalleryTile` для видео — GestureDetector → тот же полноэкранный плеер (play-бейдж на плитке); ArtifactViewer для видео тоже показывает плеер вместо статичной карточки.
- **Дубликаты** `message_parts.dart` / `message_view_parts.dart` переведены на тот же `VideoPlayerCard` (сигнатуры публичных классов сохранены).
- **Тесты** `test/g1_video_player_test.dart`: 6 именованных виджет-тестов (play/pause, повтор, полный экран, скачивание, шаринг, открытие из галереи) на подменяемой `VideoPlayerPlatform` (фейк платформенной реализации video_player), мок path_provider + реальная запись файла, подмена шеринга через `shareFilesHook`. В dev_dependencies добавлен `video_player_platform_interface: ^6.0.0` (уже транзитивная зависимость video_player).

## Живой тест (как проверить)

1. G1-LIVE-VIDEO-PLAYER: сгенерируйте видео моделью (например, grok-imagine-video-1-5). В чате: тап по видео — играет с полосой перемотки, временем, контролами; повторный тап — пауза; тап на иконке звука — mute; конец видео — иконка повтора, тап — повтор с начала. Кнопка «На весь экран» (или кнопка в контролах) — плеер на весь экран с автоплеем и кнопками Скачать/Поделиться в AppBar. «Скачать» — SnackBar «Сохранение видео…» → «Видео сохранено: vid_…mp4», файл появляется в Загрузках. «Поделиться» — системный share sheet с файлом.
2. G1-LIVE-VIDEO-GALLERY: откройте «Галерея» из меню чатов — плитка видео с play-бейджем; тап — тот же полноэкранный плеер (играет, скачивается, шарится). Проверьте и старые видео (стратичные) — теперь тоже открываются.
