# F3-cost-line-3 — замечания

## Что было не так (трассировка полного пути)

Формат usage сверен с доками (web_fetch по точным URL
`osobennosti/usage.md` и `api-reference/chat/completions.md`) — совпадает
с промптом: `cost_rub` + рублёвый алиас `cost`; в стриминге usage приходит
в последнем SSE-чанке перед `[DONE]` с пустым `choices`.

Трассировка по присланному коду (HEAD b971865):

1. API → сервис: `chat_service._roundOnce` парсит usage в ОБЕИХ режимах —
   нестрим (`_usageOf(j['usage'])`) и стрим (`yield StreamChunk('', '',
   usage: usage)` при `rawUsage is Map`), тело запроса содержит
   `stream_options: {include_usage: true}` при стриме. Путь через
   `_pacedStream` usage-чанк пропускает напрямую (фильтр
   `chunk.usage != null`).
2. Сервис → экран: `_runCompletion` копит `roundCosts`
   (`MessageCost.fromUsage`), итог — `_sumRoundCosts`, TextPart с cost
   добавляется в `reply.parts`.
3. Экран → UI: `MessageView._costWidgets` гейтится `settings.showCost`,
   форматы «≈ X ₽ · N ток.» (полная точность) и «N ток.» — контракт R4/R6
   соблюдён.

Прямой текстовый путь в присланном коде связан и соответствует контракту.
Живой тест на e1364fb показал ПОЛНОЕ отсутствие строки — по присланному
коду это возможно только когда usage не дошёл до UI (провайдер не прислал)
либо тумблер стоимости в настройках пишет не то поле. Для различения этих
случаев добавлен обязательный диагностический лог (см. ниже).

## Что сделано

- `chat_screen.dart`: обязательный пункт задачи п.1 — при отсутствии
  usage печатается лог `[cost] usage отсутствует — строка стоимости не
  показана (раундов с usage: N, модель: …, стрим: …)`.
- `test/f3_streaming_usage_test.dart` (новый): стриминговый путь usage
  РАНЕЕ НЕ БЫЛ ПОКРЫТ НИ ОДНИМ ТЕСТОМ (T2-UNIT-COST-NONSTREAM-ROUNDS —
  только нестрим). Теперь: запрос явно просит include_usage; usage с
  cost_rub доходит и резолвится в RUB/полную точность; токен-only usage
  доходит без выдуманной суммы; отсутствие usage детерминировано даёт
  ноль usage-чанков.
- `test/f3_cost_line_widget_test.dart` (новый): виджет-тесты строки —
  сумма+токены (формат «≈ 1,875 ₽ · 30 ток.», без округления до 1,88),
  только токены (без «≈ 0,00 ₽», «$0,00», «Стоимость неизвестна»),
  выключенный показ стоимости — строки нет.
- Никакие существующие тесты и код R1–R6, F1, F2 не изменены;
  TEMP-DIAG не затронут (в присланных файлах его нет).

## Чего не хватило (файлы не присланы)

- `lib/screens/settings_screen.dart` — НЕ ПРОВЕРИТЬ тумблер стоимости:
  подключён ли он к `settings.setShowCost` и не инвертирован ли. Если
  после этого фикса живой тест всё ещё не показывает строку, а лог
  `[cost] usage отсутствует` НЕ печатается — usage дошёл до UI, и
  подозревать нужно именно тумблер (файл не прислан — починить не мог).
- `lib/core/generation/generation_event.dart` — `ChatCompletionsExecutor`
  ТЕРЯЕТ `StreamChunk.usage` (не пробрасывает его в GenerationEvent).
  Для текстового пути это не задействовано (чат идёт напрямую через
  ChatService), но это незакрытый потребитель поля usage; нужен
  `UsageReceived`-ивент — файл не прислан, править не мог.
- `lib/core/utils/stream_pacer.dart`, `lib/models.dart` — пейсер
  влияет только на контент-чанки, не на usage; проверены косвенно
  (зелёная сборка + существующие тесты).

## Что стоит улучшить рядом (не чиня сейчас)

- Пробросить usage через GenerationEvent (исполнитель), чтобы медиа/
  восстановленные задачи тожеfeeding учитывались в экономике.
- Рублёвый алиас `cost` без `cost_rub` для Polza: сейчас bare `cost`
  без валюты честно даёт только токены (T2-UNIT-COST-UNSCOPED-ALIAS);
  если появится подтверждение, что Polza иногда шлёт только `cost`,
  аннотировать валюту RUB на уровне сервиса (контекст `_isPolza` там
  известен), не трогая `fromUsage`.
- Лог отсутствия usage пока только debugPrint; при желании — telemetry.

## Как проверить живым тестом

1. F3-LIVE-COST-LINE: включить стоимость в настройках → текстовый запрос
   deepseek (стрим) → под ответом «≈ X ₽ · N ток.» (полная точность).
2. F3-LIVE-COST-TOKENS-ONLY: модель без стоимости в usage → только
   «N ток.», без «≈ 0,00 ₽» и без «$0,00».
3. Если строки нет — смотреть консоль (flutter run / adb logcat):
   - `[cost] usage отсутствует …` — провайдер не прислал usage; проверить
     тело запроса (stream_options.include_usage) и ответ провайдера.
   - Лога нет, строки нет — usage дошёл до UI: проверять тумблер
     стоимости в settings_screen.dart (файл не прислан).
